### 🏋️‍♂️ Proyek Gym - Management System

Sistem informasi berbasis web yang dirancang khusus untuk mengelola operasional tempat kebugaran (gym). Sistem ini membantu digitalisasi data member, pencatatan kehadiran, hingga manajemen transaksi perpanjangan keanggotaan secara efisien. 

### 🚀 Fitur Utama

* **Manajemen Member**: Fitur lengkap untuk pendaftaran, pembaruan, dan penghapusan data keanggotaan.
* **Sistem Presensi**: Pencatatan kehadiran member secara real-time untuk memantau aktivitas harian.
* **Pelacakan Durasi**: Notifikasi otomatis atau indikator untuk memantau masa aktif keanggotaan member yang akan habis.
* **Proses Perpanjangan**: Sistem transaksi kasir yang cepat untuk menangani biaya perpanjangan paket gym.

### 👥 Multi-Aktor (3 Hak Akses)

Aplikasi ini dibangun dengan memisahkan hak akses untuk keamanan dan efisiensi kerja: 

1. **Admin / Pemilik**: Memiliki kontrol penuh atas laporan keuangan, data master, dan performa bisnis gym.
2. **Staf / Kasir**: Mengelola pendaftaran member baru, memproses transaksi pembayaran, dan melayani perpanjangan.
3. **Member**: Menampilkan kartu digital, riwayat kehadiran, serta sisa masa aktif paket latihan.

### 🛠️ Tech Stack

* **Backend Framework**: PHP / Code Igniter
* **Frontend**: HTML5, CSS3, JavaScript
* **Database**: MySQL
